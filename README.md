# HomePage-Haze（微岚主页）
一个简洁、美观、具有特色功能的纯静态个人主页。使用 HTML+CSS+JavaScript 开发。

## 特色功能
1. 方块加载动画以及遮罩层拉扯效果
2. 现代化的毛玻璃背景
3. 鼠标移动到卡片上的视差效果
4. 获得焦点时的头像旋转
5. 搜索栏打字机效果
6. 鼠标涟漪波纹和粒子效果
7. 页脚时间统计功能以及每日一言
8. 统一独立配置文件，开箱即用轻松自定义
9. 背景发光浮尘效果
10. 主卡片的呼吸“灯”效果和随多重混合 Sin 波浮动效果
11. 主卡片在无焦点时轻微浮动效果
12. 自定义指针特色小圆点样式

## 已知问题与兼容性
- 当页面处于加载的时候，左右遮罩层中间可能会有一道难以察觉的细线
- 在使用部分 Edge 浏览器访问时，自定义指针左侧可能存在闪烁光标， Chrome 及 Firefox 无此问题

## 自定义配置
本项目现已支持**统一配置文件** ，只需编辑 `js/config.js` 文件即可：
包括：
- **站点信息**
- **个人卡片**
- **社交媒体**
- **快捷按钮**
- **页脚与统计**等...
  <br> 详细配置项请直接查阅 `js/config.js` 文件内部注释
